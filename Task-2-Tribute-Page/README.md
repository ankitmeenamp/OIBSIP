# 🌟 OIBSIP Level 2 - Task 2 Tribute Page

A responsive and visually polished tribute page dedicated to
Dr. A. P. J. Abdul Kalam.

This project was created as part of the Oasis Infobyte Internship
Program (OIBSIP).

## 🎯 Task Objective

The objective of this task is to design and develop a visually
engaging tribute page dedicated to a historical figure, scientist,
artist, or public figure.

## 🛠️ Tech Stack

- HTML5
- CSS3
- Google Fonts

## ✨ Features

- Responsive navigation bar
- Hero section
- Prominent subject image
- About/Biography section
- Timeline of important milestones
- Inspirational quote section
- Legacy section
- Responsive design
- Mobile-friendly layout
- Smooth scrolling
- Two-font typography system
- Multiple section backgrounds
