# ✅ OIBSIP Level 2 - Task 3 To-Do Web App

A professional and responsive To-Do web application built as part
of the Oasis Infobyte Internship Program (OIBSIP).

The application allows users to create, manage, edit, complete,
and delete daily tasks.

## 🎯 Task Objective

The objective of this task is to develop an interactive To-Do list
application that allows users to manage daily tasks with add,
complete, edit, and delete functionality.

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Browser LocalStorage

## ✨ Features

### Task Management

- Add new tasks
- Mark tasks as completed
- Move completed tasks to the Completed Tasks list
- Edit existing tasks
- Delete tasks
- Clear all completed tasks

### Task Statistics

The application displays:

- Pending task count
- Completed task count

### Data Persistence

Tasks are stored using browser `localStorage`, so tasks remain
available after refreshing the page.

### Timestamp

Each task displays its creation time.

Completed tasks also display their completion time.

### Empty States

Friendly messages are displayed when:

- There are no pending tasks
- There are no completed tasks

### Responsive Design

The application works across:

- Desktop
- Laptop
- Tablet
- Mobile

### Keyboard Support

- `Enter` - Add/Save task
- `Escape` - Close edit modal
